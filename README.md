# Ringlume — Voice AI Receptionist

Static marketing site for a Voice AI receptionist product.

| Stack | |
|-------|---|
| Framework | **Astro 7** (static) |
| Styling | **Tailwind CSS v4** |
| Package manager | **pnpm** |
| Hosting | **Netlify** |

```sh
pnpm install
pnpm dev       # http://localhost:4321
pnpm build     # static build → dist/
pnpm preview   # serve dist/
```

See `AGENTS.md` for architecture, design system, and conventions.
